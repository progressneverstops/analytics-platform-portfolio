# Take-Home Simulation

A compact take-home style exercise to show end-to-end execution: dataset → questions → SQL → analysis.

## Contents

- `dataset/` sample CSVs
- `questions/` prompt and success criteria
- `sql/` queries answering the prompt
- `analysis/` short written interpretation

## How to use

1. Read `questions/README.md`
2. Load `dataset/sample_events.csv` into SQLite
3. Run `sql/queries.sql`
4. Review `analysis/analysis.md`
